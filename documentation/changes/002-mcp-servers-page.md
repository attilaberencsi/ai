## Findings (2026-10-09)
- No documented `claude://` or `claude-cli://` link installs an MCP server. Official docs (claude.com/docs/connectors/custom/remote-mcp) describe only the manual UI flow for remote URLs and `.mcpb` drag-and-drop for local Desktop extensions.
- `claude-cli://open` (code.claude.com/docs/en/deep-links) takes only `q`, `cwd`, `repo`; it opens a terminal session with a pre-filled, unsent prompt. It does not run `mcp add`.
- `claude://` is handled by Claude Desktop, documented only for SSH sessions.
- Claude Desktop local stdio servers: only via `.mcpb` bundle or editing `claude_desktop_config.json`; no link. Offer copyable JSON snippet.
- Browsers/GitHub Markdown may block custom schemes; links on our own page (JS `window.location`/anchor) are fine.
